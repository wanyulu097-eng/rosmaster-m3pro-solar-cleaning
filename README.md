# 光伏组件自主导航与覆盖清洁机器人

本仓库分享 ROSMASTER M3 PRO 项目中**相机与机械臂**部分的知识，欢迎通过 Issue 和 Pull Request 补充可验证的资料、复现实验和实现。整体目标是：真实板面识别 → 可核实的清洁区域 → 坐标与工具几何 → 机械臂执行 → 清洁效果验证。导航到位由整体项目协作解决；现阶段保留原夹爪。

**项目尚未完成自主清洁。** 已有摄像头预览、真实 RGB-D 数据、相机坐标候选点集、阶段手眼候选及覆盖软件原型；这些成果分别尚未证明完整板面识别、机械臂安全接触或实物清洁。具体状态见[项目进展](docs/project-status.md)。
