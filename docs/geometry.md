# 相机与机械臂几何

真实彩深帧已用于构造条件相机光学坐标点集。要得到可供机械臂使用的当前点，还需与相机—机械臂外参、实际关节状态及工具接触点对应，并核验彩深配准与尺度。历史帧的板面位置不能跨场景直接复用。

2026-10-13 的 PARK 手眼候选曾在另一组板位的七个姿态得到阶段性验证，平移 RMS 为 9.78 mm、旋转 RMS 为 1.03°。后续接近同一机械臂姿态的复现中，视觉板位仍有较大变化；可能因素尚未隔离。故该候选是诊断证据，不应作为当前已验证控制外参发布。

曾在诊断固件下获得本车六轴实测反馈；恢复生产固件后，相同 ROS 反馈路径未得到同样证据。官方示例中的目标角、逆解角或软件命令缓存不等于真实关节角，`/joint_states` 的名字本身也不证明其数据来源。需要与固件版本匹配的实测反馈或独立测量。

请贡献者在提出变换链时写明每个坐标系、矩阵方向、单位、时间戳、观测值与假设；以独立姿态和物理参考验证精度。不得把离线矩阵组合或历史成功等同当前安全动作许可。
