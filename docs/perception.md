# 板面识别与彩深证据

## 已有结果

- 车端白框预览曾在真实相机画面上给出候选；这是视觉候选而非完整区域验收。
- 已发现固定横向窗口会漏掉真实左边缘；去掉固定窗口的离线候选改善了一些帧，但会把部分非板矩形视为候选，也出现背景边被当作边界的反例。候选未成为可靠的光伏板存在性判定。
- 某些真实帧中的板面下沿被夹爪遮挡或画面截断，模型仍可给出部分候选，因此不能从存在候选推断整板完整可见。
- 彩色与深度分析在两帧上显示顶部深度阶跃对应板体对背景的遮挡轮廓；所观测彩色外缘和深度阶跃存在约 3.8 像素的位置差。该差异可能涉及轮廓取样或配准，不能单独当成全图修正值。左右边存在深度空洞，框和玻璃深度接近，不宜用深度阶跃区分内边界。

## 待验证

应在未参与规则设计的不同场景中，同时记录真板漏检、背景误选、出框和前景遮挡情况。需独立标注或其他可追溯参考；单帧候选、平面残差或模型间一致性不能代替实际边界真值。彩深配准、尺度和不确定度需要独立物理证据。

这些结果来自本地项目实验记录和历史保存帧；目前未公开原始图像与群聊材料，因此这里是可供讨论的实验摘要，不是完整复现实验包。
